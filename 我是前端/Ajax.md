# 简介

**是什么：**客户端向服务器发送请求，服务器返回结果，**无刷新获取数据**

**例	子：**搜索提示，鼠标悬浮提示等，懒加载，只有发生指定事件时才发生加载，且页面并没有发生刷新



**优	点：**无需刷新页面就可以与服务器实现通信

​				可以根据用户事件来更新指定页面内容

**缺	点：**没有浏览历史，不能回退

​				存在跨域问题（默认不能向其他网页发请求）

​				爬虫爬不到数据



# HTTP协议

规定了浏览器和服务器之间的传输约定



## 请求报文

客户端向服务器端发送请求请求的格式

| 格式   | 组成                                  |
| ------ | ------------------------------------- |
| 请求行 | 请求类型（GET、POST等）               |
|        | URL的路径                             |
|        | HTTP协议的版本                        |
|        |                                       |
| 请求头 | 类型： 内容（例：Cookie： name=AAA）  |
|        |                                       |
| 空行   |                                       |
|        |                                       |
| 请求体 | （例：username=admin&password=admin） |



## 响应报文

| 格式   | 组成                                           |
| ------ | ---------------------------------------------- |
| 响应行 | HTTP协议版本                                   |
|        | 响应状态码（例：如404等）                      |
|        | 响应状态字符串（例：OK等，和响应状态码相对应） |
|        |                                                |
| 响应头 | 类型： 内容（例：Cookie： name=AAA）           |
|        |                                                |
| 响应体 |                                                |

~~~http
<html>
	<head>
	</head>
	
	<body>
		<h1>AAA<h1>
	</body>
</html>
~~~
