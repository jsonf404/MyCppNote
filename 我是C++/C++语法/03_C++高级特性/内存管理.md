# 内存管理

C++ 提供了多种内存管理方式，包括传统的 C 风格的 `malloc` 和 `free`，以及 C++ 专用的 `new` 和 `delete`。

理解这些内存管理方法对于编写高效、安全的 C++ 程序至关重要。

本文将详细介绍这些内存管理方法，包含基本用法、复杂操作（如 `realloc`），并配以实际案例和代码示例。

**先了解C++内存分区：[C++内存分区模型](../01_C++语法基础/C++基础语法.md#C++内存分区模型)** 



## C风格内存管理

| 函数                     | 作用             | 特点           |
| ------------------------ | ---------------- | -------------- |
| `malloc(size)`           | 分配指定字节内存 | 未初始化       |
| `calloc(n, size)`        | 分配 n 个对象    | **初始化为 0** |
| `realloc(ptr, new_size)` | 扩容/缩容        | 可能移动内存   |
| `free(ptr)`              | 释放内存         | 必须手动调用   |



### malloc&free

1. `malloc`（memory allocation）用于在堆上分配指定字节数的内存。其原型如下：

   ```cpp
   #include <cstdlib>
   void* malloc(size_t size);
   ```

   > **返回值**：指向分配内存的指针，如果分配失败则返回 `nullptr`。

---

2. `free` 用于释放之前由 `malloc`、`calloc` 或 `realloc` 分配的内存。其原型如下：

   ```cpp
   void free(void* ptr);
   ```

---

3. **注意：** 

   - **类型转换**：`malloc` 返回 `void*`，需要显式转换为所需类型的指针。

   - **初始化**：`malloc` 分配的内存未初始化，内容不确定。

   - **释放对应性**：由 `malloc` 分配的内存必须使用 `free` 释放，避免使用 `delete`。

---

```cpp
#include <iostream>
#include <cstdlib>

int main()
{
	// 使用malloc分配内存
	int* ptr = (int*)malloc(sizeof(int) * 5); // 分配一个包含5个整数的数组
	if (ptr == nullptr) 
	{
		std::cerr << "内存分配失败" << std::endl;
		return 1; // 退出程序
	}
	// 使用分配的内存
	for (int i = 0; i < 5; ++i) 
	{
		ptr[i] = i + 1; // 初始化数组元素
        //*(ptr+i) = i + 1;
	}
	// 输出数组元素
	std::cout << "数组元素: ";
	for (int i = 0; i < 5; ++i) 
	{
		std::cout << ptr[i] << " ";
	}
	std::cout << std::endl;
	// 释放分配的内存
	free(ptr);
	return 0;
}
```



### realloc

> **对已分配内存进行“原地扩展或迁移”**。是C风格的自动扩容

```cpp
void* realloc(void* ptr, size_t new_size);
```

> `ptr`：原内存指针（必须来自 `malloc/calloc/realloc`）
>
> `new_size`：新的大小（字节）
>
> 失败返回 `nullptr` 

1. 要么就地扩容缩小、要么整体copy迁移，free原本内存

2. 不能对C++对象使用，只能搭配 `malloc` 、`free` 

---

```cpp
#include <iostream>
#include <cstdlib>

int main()
{
  int *arr = (int *)malloc(5 * sizeof(int));
  if (arr == nullptr)
  {
    std::cerr << "Memory allocation failed" << std::endl;
    return 1;
  }
  for (int i = 0; i < 5; i++)
  {
    arr[i] = i + 1;
    std::cout << arr[i] << " ";
  }
  std::cout << std::endl;

  int *newArr = (int *)realloc(arr, 10 * sizeof(int));
  if (newArr == nullptr)
  {
    std::cerr << "Memory reallocation failed" << std::endl;
    free(arr); // 新数组分配失败，释放原数组
    return 1;
  }
  else
  {
    arr = newArr; // 更新指针指向新数组
  }

  for (int i = 5; i < 10; i++)
  {
    arr[i] = i + 1;
    std::cout << arr[i] << " ";
  }
  free(arr);
  return 0;
}
```



### 案例

#### 简单的动态数组

> 类似于 `vector` 

```cpp
/*
实现一个简单的动态数组类，支持基本的数组操作，如添加元素、删除元素、访问元素和自动扩容
*/
#include <iostream>
class DynamicArray
{
public:
  DynamicArray() : size(0), capacity(2), arr((int *)malloc(capacity * sizeof(int)))
  {
    if (arr == nullptr)
    {
      std::cerr << "Error: Failed to allocate memory for dynamic array." << std::endl;
      throw std::bad_alloc(); // 构造函数不能直接返回，要不然其还是执行完了，所以抛出异常
    }
  }

  ~DynamicArray()
  {
    free(arr);
  }

  void add(int value)
  {
    if (size >= capacity)
    {
      capacity *= 2; // 扩容
      resize(capacity);
    }

    arr[size++] = value; // 添加元素并更新大小
  }

  int get(size_t index) const
  {
    if (index >= size)
    {
      std::cerr << "Error: Index out of bounds." << std::endl;
      throw std::out_of_range("Index out of bounds");
    }
    return arr[index];
  }

  size_t getSize() const
  {
    return size;
  }

private:
  void resize(size_t newCapacity)
  {
    int *newArr = (int *)realloc(arr, newCapacity * sizeof(int));
    if (newArr == nullptr)
    {
      std::cerr << "Error: Failed to reallocate memory for dynamic array." << std::endl;
      free(arr);              // 释放原数组
      throw std::bad_alloc(); // 抛出异常
    }
    arr = newArr;
  }

  size_t size;     // 当前元素数量
  size_t capacity; // 数组容量
  int *arr;        // 存储元素的数组
};

int main()
{
  try
  {
    DynamicArray dynamicArray;
    for (int i = 0; i < 10; i++)
    {
      dynamicArray.add(i + 1);
      std::cout << "Added: " << i + 1 << ", Size: " << dynamicArray.getSize() << std::endl;
    }

    for (size_t i = 0; i < dynamicArray.getSize(); i++)
    {
      std::cout << "Element at index " << i << ": " << dynamicArray.get(i) << std::endl;
    }
  }
  catch (const std::bad_alloc &e)
  {
    std::cerr << e.what() << '\n';
  }
  catch (const std::out_of_range &e)
  {
    std::cerr << e.what() << '\n';
  }
}
```



#### 简单的内存池

```cpp
#include <iostream>
#include <stack>

class MemoryPool
{
public:
  MemoryPool(size_t objSize, size_t poolSize) : objSize(objSize), poolSize(poolSize)
  {
    pool = malloc(objSize * poolSize);
    if (pool == nullptr)
    {
      std::cerr << "Error: Failed to allocate memory for memory pool." << std::endl;
      throw std::bad_alloc();
    }
    // 初始化空闲列表
    for (size_t i = 0; i < poolSize; ++i)
    {
      freeList.push((char *)(pool) + i * objSize);
      // void*类型不能进行算术运算，所以先转换成char*类型，再进行地址计算
      // 因为char类型的大小为1字节，所以每次增加objSize字节就能得到下一个对象的地址。
    }
  }

  ~MemoryPool()
  {
    free(pool);
  }

  void *allocate()
  {
    if (freeList.empty())
    {
      std::cerr << "Error: Memory pool exhausted." << std::endl;
      throw std::bad_alloc();
    }
    void *obj = freeList.top();
    freeList.pop();
    return obj;
  }

  void deallocate(void *obj)
  {
    freeList.push(obj);
  }

private:
  size_t objSize;              // 每个对象的大小
  size_t poolSize;             // 内存池的总大小
  void *pool;                  // 内存池的起始地址
  std::stack<void *> freeList; // 空闲对象的栈
};

int main()
{
  MemoryPool pool(sizeof(int), 10); // 创建一个内存池，每个对象大小为int，池大小为10

  int *a = (int *)pool.allocate(); // 从内存池分配一个int对象
  *a = 42;
  std::cout << "Allocated int: " << *a << std::endl;

  pool.deallocate(a); // 将对象返回内存池

  return 0;
}
```



## C++内存管理

> C++ 提供了更高层次的内存管理操作符：`new` 和 `delete`，它们不仅分配和释放内存，还调用构造函数和析构函数，提供类型安全。

| 关键字     | 作用                    |
| ---------- | ----------------------- |
| `new`      | 分配对象 + 调用构造函数 |
| `delete`   | 释放对象 + 调用析构函数 |
| `new[]`    | 分配数组                |
| `delete[]` | 释放数组                |

### 基本知识

1. `new`用于在堆上分配对象，并调用其构造函数。

2. `delete` 删除对象类型和 `new` 要匹配

   ```cpp
   // 1. 单个对象
   Type* ptr = new Type(parameters);
   delete ptr;
   
   // 2. 数组
   Type* array = new Type[size];
   delete[] ptr;
   ```

   ---

   ```cpp
   class student
   {
   public:
   	student(int a, int b) : a(a), b(b) {}
   	int a;
   	int b;
   };
   
   int main()
   {
   	student *s = new student(1, 2);
   	std::cout << s->a << " " << s->b << std::endl;
   
   	int *arr = new int[5];
   	for (int i = 0; i < 5; i++)
   	{
   		arr[i] = i + 1;
   		std::cout << arr[i] << " ";
   	}
   	std::cout << std::endl;
   
   	delete s;
   	delete[] arr;
   	return 0;
   }
   ```



### 与C风格区别

| 维度         | `malloc / free`   | `new / delete`          |
| ------------ | ----------------- | ----------------------- |
| 本质         | 纯内存分配/释放   | **对象构造 + 内存分配** |
| **构造函数** | ❌ 不调用          | ✅ 自动调用              |
| **析构函数** | ❌ 不调用          | ✅ 自动调用              |
| 返回类型     | `void*`（需强转） | 类型安全指针            |
| 失败行为     | 返回 `NULL`       | 抛异常（默认）          |
| 可重载       | ❌                 | ✅（operator new）       |

> `free` 没有析构调用，单纯释放内存可能内存泄漏



### 异常安全的new

```cpp
#include <iostream>
#include <new> // 包含 std::nothrow

int main() 
{
    int* p = new(std::nothrow) int;
    if (p == nullptr) 
    {
        std::cerr << "Memory allocation failed" << std::endl;
        return 1;
    }
    *p = 100;
    std::cout << "Value: " << *p << std::endl;
    delete p;
    return 0;
}
```



## RAII

**RAII = Resource Acquisition Is Initialization** （**资源获取即初始化**）

**资源在对象构造时获取，在析构时自动释放**



### 内存泄漏

> 程序申请的内存没有被释放，并且之后再也无法访问这块内存

为了避免内存泄漏：

- **确保每个** `new` **有对应的** `delete`。

- **使用** `RAII` **和智能指针**：自动管理资源，避免手动管理内存。

- **工具辅助**：使用工具如 `Valgrind` 检测内存泄漏。
